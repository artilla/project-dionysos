화면의 우선순위

새 현황 검색은 다섯 조건과 검색 버튼으로 구성합니다. 전체 월·전국 설정은 더보기에 둡니다. 저장 현황과 진행 상태는 간단히 표시하고, 결과 내 검색은 목록 바로 위에서 변경 즉시 적용합니다.

현재 표현새 표현과 동작
이번 조건으로 조회다섯 조건을 정하고 검색 버튼 실행
모든 조건 조회더보기 → 전체 월·전국으로 설정
흩어진 검색 조건결과 내 검색 영역에 통합
대형 연결·진행 카드저장 현황 요약 + 진행 중에만 얇은 상태 표시

결과가 없을 때도 이유를 구분합니다.

  • 가져온 범위에서 일치하는 곳이 없음 → 필터 초기화
  • 해당 월·지역·유형을 아직 가져오지 않음 → 카드에 필요한 범위를 미리 입력
  • 가져오는 중이거나 일부 실패 → 현재 결과 유지 + 계속·재시도

직접 확인할 수 있는 시안 상태

아래 버튼은 예시 데이터의 상태만 바꿉니다. 실행 중인 실제 앱에는 영향을 주지 않습니다.

구현 시 유지할 규칙

결과 필터와 가져오기 초안·실행 범위·시작 조건을 별도 상태로 관리합니다. 검색할 때 다섯 조건을 한 번 적용하고, 이전 결과의 검색어·입실일·주말·대기 필터는 해제합니다. 입력하는 동안에는 기존 결과를 유지합니다. 가져오는 중 결과 조건을 바꿔도 시작 조건과 수집 범위는 바뀌지 않습니다. 새 현황은 완료한 범위부터 기존 결과에 합치며, 실패를 빈방 없음으로 처리하지 않습니다. 월말 연박에 필요한 다음 달은 수집 과정에서 함께 확인합니다.

디자인 확인을 위한 시설·예약 예시입니다. 실제 예약 정보와 연결되지 않습니다.
