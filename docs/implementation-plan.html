01 / SCOPE

한 달을 고르면, 가능한 숲이 모입니다.

실제 데이터로 통합 조회

원천 지역·휴양림 목록을 조회하고 월·지역·전체/숙소/야영장 조건의 대상 범위를 한 작업으로 묶습니다.

정확한 입실 가능 날짜

인원·동일 시설 연박·금토 입실 조건. 달력/카드/상세의 조건과 숫자를 일치시킵니다.

진행과 복구

확인한 범위부터 표시. 중단·재접속·로그인 만료 후 이어가기와 실패한 범위 재시도.

기존 탐색 경험 유지

찜·검색·정렬·상세 모달·모바일 레이아웃·공식 사이트 연결. 예시 데이터로 자동 대체하지 않습니다.

배포는 별도 작업입니다. 이번 구현은 로컬에서 동작하는 실제 서비스와 Sites 대상 서버 빌드를 만듭니다. .openai/hosting.json에는 DB 바인딩만 있으며 사이트 등록은 아직 하지 않았습니다. 배포 시 ID, PASSWORD, SESSION_SECRET(32자 이상), OWNER_USER_ID를 서버 환경변수로 설정하고 소유자 전용 접근을 확인해야 합니다. 자동 예약·결제·주기적 모니터링·공개 계정 공유를 추가하지 않습니다.

02 / BUILD ORDER

검증한 HTTP 경로를 그대로 연결합니다.

01 · SOURCE

로그인과 원천 어댑터

  • fetch + 쿠키 저장소 + CSRF로 일반 로그인.
  • 지역·휴양림·조회 가능 월·시설 유형 조회.
  • NetFunnel의 정상 진입·대기·완료 절차.
  • 시설 최대 5개씩 날짜 조회. 알 수 없는 응답·차단·인증 만료는 중단.
02 · DATA & EXECUTION

저장과 배치 API

  • SQLite/D1 공통 저장소, 암호화된 서버 세션.
  • 작업 시작·한 배치 처리·상태·중단·이어가기·실패 재시도 API.
  • 임대로 중복 요청을 제한하고 완료 결과와 조회 시각을 보존.
  • 탭을 닫으면 수집도 멈춤. 재접속 시 사용자가 이어서 실행.
03 · AVAILABILITY & UI

실제 화면 연결

  • 원천 상태 정규화, 같은 시설 연박과 월 경계 처리.
  • 일반 공실 + 정원 + 숙박일수 조건으로 입실일 집계.
  • 전국/지역, 전체/숙소/야영장, 검색·정렬·찜.
  • 진행·부분 실패·확인 필요·이전 조회 시각과 다음 행동 표시.
04 · RUN & CHECK

로컬 실행과 검증

  • 계산·파싱·세션·배치 재개와 실패 보존 테스트.
  • 실제 소수 휴양림에서 로그인→조회→목록→상세 확인.
  • 데스크톱·좁은 화면에서 필터·모달·찜·재로드·오류 복구.
  • Sites 서버 빌드 확인. 배포 환경 접속 검증은 별도.
03 / CODE

화면·판정·원천을 분리합니다.

index.html                  기존 독립 프로토타입 보존
web/                        실제 서비스 화면
server/foresttrip.mjs        HTTP 로그인·대기열·원천 조회
server/domain.mjs            상태·연박·집계
server/store.mjs             SQLite/D1 공통 저장소·암호화
server/app.mjs               API·배치 진행·복구
server/local.mjs             localhost 실행
server/worker.mjs            Sites / Workers 진입점
tests/                      네트워크 없는 핵심 회귀 테스트
docs/                       수정된 아키텍처·계획서
.local/                     로컬 DB·암호화 키 (배포 제외)
.env                        서버에서만 읽는 기존 자격증명

실행 명령

npm install → npm start. npm test로 핵심 회귀 테스트, npm run build로 웹·서버 빌드를 확인합니다. Node.js 22.13 이상이 필요합니다. 화면은 http://127.0.0.1:5178/에서 열고 연결 후 조회를 시작합니다. PORT 환경변수로 포트를 바꿀 수 있습니다. 서버를 종료하려면 실행 터미널에서 Ctrl+C를 누릅니다.

04 / COMPLETION

현재 구현과 실제 검증 범위를 함께 남깁니다.

범위완료 기준
원천 HTTP기존 브라우저 쿠키 없이 정상 로그인·대기열·시설·날짜 조회 성공.
예약 가능 계산Y이면서 예약 건수 0. 휴무/기간/정원/연박 제한 반영. 누락은 확인 필요. 다른 객실 날짜를 이어 붙이지 않음.
진행과 재개조회 범위·성공·실패·남은 배치가 보임. 중단과 재시도 후 성공 결과와 시각 유지.
화면실데이터 표시·필터·달력·상세·찜·재로드 및 관련 복구. 샘플 fallback 없음.
전국 및 Sites전국 모든 대상과 Sites 배포 런타임의 성공은 별도 검증 전까지 미확인으로 표시.
